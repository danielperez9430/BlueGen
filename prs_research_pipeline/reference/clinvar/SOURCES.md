# ClinVar Reference Data — Sources & Attribution

## Data Source

- **Database:** ClinVar — NCBI's archive of clinically relevant genetic variants
- **Maintained by:** National Center for Biotechnology Information (NCBI), U.S. National Library of Medicine, National Institutes of Health (NIH)
- **Download URL:** `https://ftp.ncbi.nlm.nih.gov/pub/clinvar/vcf_GRCh37/`
- **Format:** VCF v4.1 (GRCh37/hg19)
- **Current release:** `clinvar_20260530.vcf.gz` (2026-05-30)
- **Size:** ~187 MB compressed (~4.4 million variant records)
- **Access:** Free and open — no registration, API key, or authentication required

## How ClinVar Classifications Work

ClinVar aggregates variant classifications submitted by clinical laboratories, research groups, and expert panels. Each variant receives:

| Field | Description |
|-------|-------------|
| `CLNSIG` | Aggregate clinical significance (Pathogenic, Likely_pathogenic, Uncertain_significance, Likely_benign, Benign, etc.) |
| `CLNREVSTAT` | Review status (practice_guideline, reviewed_by_expert_panel, criteria_provided, etc.) |
| `CLNDN` | Associated disease name(s) |
| `GENEINFO` | Gene symbol:GeneID pairs |
| `RS` | dbSNP reference SNP ID |

**Important:** Variant classifications can differ between submitting laboratories. The `CLNSIG` field reflects the aggregate classification. Variants with conflicting classifications (`Conflicting_classifications_of_pathogenicity`) are excluded from the pathogenic report by default.

## How This Project Uses ClinVar

1. **Download:** The ClinVar VCF (GRCh37) is downloaded once via `scripts/setup/download_clinvar.py` and cached locally
2. **Annotation:** `scripts/clinical/clinvar_annotator.py` intersects the user's WGS VCF with ClinVar using positional overlap (`tabix -R`) + exact REF/ALT matching
3. **Filtering:** Only variants classified as `Pathogenic`, `Likely_pathogenic`, `Pathogenic/Likely_pathogenic`, or established risk alleles are reported
4. **Output:** Results are written to `clinvar/clinvar_pathogenic_variants.json` and displayed in the comprehensive HTML report
